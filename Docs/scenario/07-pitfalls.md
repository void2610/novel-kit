# 7. 制約と落とし穴

シナリオは mruby（の C# 実装 MRubyCS）で動く。通常の Ruby と同じ気持ちで書けるが、
いくつか制約とハマりどころがある。

## 一時変数は命令を跨いで持ち越さない

各命令（セリフ・選択肢など）の裏では実行の一時停止と再開が起きており、mruby の制約で
**ローカル変数（一時変数）が命令を跨ぐと失われる場合がある**。

```ruby
# ✕ 危険: 選択結果を長く持ち回る
n = choose(["A", "B"])
alice "……そう。"
narration "しばらくして。"
if n == 0        # ここで n が消えていることがある
  ...
end

# ◯ 安全: 直後に使う
n = choose(["A", "B"])
if n == 0
  ...
end

# ◯ 安全: 持ち回るならフラグに残す
choose(["A", "B"], key: :picked)
alice "……そう。"
narration "しばらくして。"
if val(:picked) == 0
  ...
end
```

**原則: 選択結果・計算結果を後で使うなら、必ず `flag` か `key:` 付き `choose` で残す。**

## `chara` 宣言を忘れると undefined method

```ruby
alice "こんにちは。"    # ✕ chara :alice を書いていない → 実行時エラー
```

キャラ名で話すには、そのシナリオファイル内で先に `chara :alice` を書くこと
（自動でメソッドが生える仕組みではなく、`chara` が明示的に定義している）。

## `exit` は使わない

キャラ退場は `exit_chara`。`exit` は Ruby 本体の「プログラム終了」命令と衝突する。

## 値は整数だけ

`flag` に入れられるのは整数のみ。`flag :name, "アリス"` や `flag :rate, 0.5` はできない。
文字列を出し分けたいときは番号で分岐する:

```ruby
flag :heroine, 1
# ...
case val(:heroine)
when 1 then alice "私を選んでくれたのね。"
when 2 then bob "俺かよ。"
end
```

## `__` 始まりの名前は予約

フラグ名・選択肢キーに `__`（アンダースコア 2 つ）始まりの名前を使わない。
内部の一時領域として扱われ、**セーブに残らない**。

## 未配線の命令は「静かに」何もしない

`portrait` / `bg` / `se` / `shake` などは、ゲーム側が対応機能を配線していない場合
エラーにならず単に無視される（開発中は初回のみ Console 警告）。
「書いたのに出ない」ときはタイプミスか未配線を疑う。キーのタイプミス
（存在しない立ち絵キーなど）もエラーで止まらないことがあるので、必ず実機で通し確認する。

## 高度な Ruby 機能は一部使えない

普通にシナリオを書く分には出会わないが、凝ったことをする場合の注意:

- 実行時の `eval`（文字列をコードとして実行）は使えない。
- `method_missing` は使えない（`chara` が `define_method` 方式なのはこのため）。
- `&:to_f` のような Symbol#to_proc 省略記法は使えない。明示ブロック `{ |x| x.to_f }` を使う。

共通のヘルパ関数（糖衣）を自作したい場合は、シナリオファイルに直接書くか、
エンジニアに依頼して追加プリアンブル（全シナリオ共通の定義ファイル）に入れてもらう。

## FAQ

**Q. セリフの途中で改行したい**
A. 本文に `\n` を書く: `alice "一行目\n二行目"`

**Q. 別のシナリオファイルへジャンプしたい**
A. できない設計。フラグを立ててシナリオを終え、次にどれを再生するかはゲーム側が決める（[1 章](./01-basics.md)参照）。

**Q. 文法エラーの見つけ方は**
A. `.rb` 保存時に Unity の Console に出る。メニュー **Novel > Validate Scenarios** で一括チェックもできる。

**Q. 既読スキップ・オート再生のために書くことは**
A. なし。既読管理・オート/スキップは本文から自動で処理される。

**Q. 使える立ち絵キー・背景キー・音のキーの一覧は**
A. ライブラリではなくゲーム側のカタログで決まる。プロジェクトの資料を参照するか、エンジニアに確認する。
