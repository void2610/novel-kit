# 6. 命令・タグ早見表

全命令・全タグのリファレンス。各命令の詳しい説明は該当章を参照。

## 命令一覧

### テキスト（[2 章](./02-text.md)）

| 命令 | 引数 | 説明 |
|---|---|---|
| `chara :id` | キャラ id | キャラ名命令を生やす。以降 `id "…"` で話せる |
| `id "…"` | 本文, `as:` 表示名 | セリフ（`chara` 宣言後）。`as:` でその行の表示名を上書き |
| `say` | 話者 id, 本文, 立ち絵キー(省略可), `display_as:` | セリフの基本形。第 3 引数で同時に立ち絵切替。1 引数ならナレーション |
| `narration` | 本文 | 地の文（話者なし） |

### 分岐・状態（[3 章](./03-branching.md)）

| 命令 | 引数 | 説明 |
|---|---|---|
| `choose` | 選択肢の配列, `key:` 名前(省略可) | 選択肢を出し、選んだ番号（0 始まり）を返す。`key:` 付きはセーブに残る |
| `flag` | 名前, 値(省略時 1) | フラグ/変数を設定（整数のみ）。セーブ対象 |
| `val` | 名前 | 値を読む。未設定は 0 |
| `flag?` | 名前 | 真偽判定（0 以外で真） |

### 画面（[4 章](./04-staging.md)）

| 命令 | 引数 | 説明 |
|---|---|---|
| `stage` | レイアウト id, キャスト(配列/ハッシュ, 省略可) | 場面宣言。既定レイアウト: `:single`〜`:penta`（1〜5 人） |
| `portrait` | キャラ id, 立ち絵キー | 立ち絵の表示・表情替え |
| `exit_chara` | キャラ id | 指定キャラを退場 |
| `clear_stage` | — | 全員退場（レイアウトは維持） |
| `bg` | 背景キー | 背景差し替え |
| `still` | 一枚絵キー | イベント CG 表示 |
| `image` | 画像キー | 補足画像を画面中央に表示 |
| `hide_image` | — | 中央の補足画像を消す |
| `hide_message_window` | — | メッセージウィンドウを隠す |
| `show_message_window` | — | メッセージウィンドウを戻す |
| `clear_message` | — | 表示中のセリフ・話者名を消す（ウィンドウは残す） |

### 音・演出・その他（[5 章](./05-audio-effects.md)）

| 命令 | 引数 | 説明 |
|---|---|---|
| `bgm` | BGM キー | BGM 再生。`bgm ""`（または引数なし）で停止 |
| `se` | SE キー | 効果音を 1 回再生 |
| `se_loop` | SE キー, 間隔秒(0.5), 回数(3) | 効果音の繰り返し再生 |
| `wait` | 秒 | 明示待機 |
| `shake` | 強さ(1.0) | 画面（カメラ）揺れ ※要ゲーム側配線 |
| `flash` | 秒(0.2) | フラッシュ ※同上 |
| `fade_out` / `fade_in` | 秒(1.0) | フェード ※同上 |
| `blackout` | 秒(0.0) | 即時暗転 ※同上 |
| `world_effect` | エフェクト名, 数値引数... | 汎用世界エフェクト ※内容はプロジェクト定義 |
| `cmd` | 命令名, 引数名: 値, ... | プロジェクト独自命令の汎用呼び出し |

## インラインタグ一覧（[2 章](./02-text.md)）

| タグ | 効果 |
|---|---|
| `<w=N>` | N 秒待つ |
| `<p>` | クリック待ち |
| `<speed=2x>…</speed>` | 区間の表示速度（`2x` = 2 倍速、`0.5` = 半分） |
| `<fast>` | 以降を即時表示 |
| `<shake>…</shake>` | 文字を揺らす |
| `<wave>…</wave>` | 文字を波打たせる |
| `<ruby=よみ>親文字</ruby>` | ふりがな |
| `<color>` `<size>` `<b>` `<i>` `<u>` `<s>` `<sup>` `<sub>` `<mark>` `<link>` `<sprite>` `<font>` `<align>` ほか | TMP スタイル（そのまま反映） |
| `<noparse>…</noparse>` | 囲んだ区間をタグ解釈せずそのまま表示 |

対応外の `<` はそのまま文字として表示される。

## ルビ辞書（`Resources/Novel/ruby.rb`）

| 書式 | 説明 |
|---|---|
| `ruby '親文字', 'よみ'` | 出現のたびにルビを振る |
| `ruby '親文字', 'よみ', :first` | 初出の 1 回だけ振る（`:once` も同義） |
