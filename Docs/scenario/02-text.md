# 2. セリフとテキスト表現

## キャラの登場宣言とセリフ

セリフを話すキャラは、シナリオの最初に `chara` で「このキャラが登場します」と宣言しておく。
宣言したキャラは、**キャラ名を行の頭に書くだけ** でセリフになる。

```ruby
chara :alice
chara :bob

alice "こんにちは。"
bob "やあ。"
```

- 画面に出る話者名（「アリス」など）や立ち絵は、キャラ名をもとにゲーム側の設定
  （キャラカタログ）から引かれる。**使えるキャラ名の一覧は Unity のメニュー
  Novel > Project Reference で確認できる**（Unity を開けない場合はプロジェクトの資料か
  エンジニアに確認）。設定にない名前を使うと、名前がそのまま画面に出てしまう。
- `chara :alice` を書き忘れて `alice "…"` と書くと、再生したときに
  「そんな言葉は知らない」というエラー（undefined method）になる。

### 表示名だけ変える（正体を伏せる）

セリフの後ろに `, as: "…"` と書き添えると、**その行だけ** 話者の表示名を変えられる。
正体を伏せたいときや、名前がまだ判明していないキャラに。

```ruby
alice "……誰かしら、あなた。", as: "？？？"
alice "私はアリスよ。"                       # 何も書かなければ通常の表示名に戻る
```

### カタログにいないキャラに一度だけ喋らせる

通行人やモノローグの声など、**キャラ一覧に登録するほどではない単発のキャラ**は、
シナリオの先頭で `speaker` と宣言すればそのまま喋らせられる。

```ruby
speaker "？？？"                  # 表示名は書いた名前そのまま
speaker :claude, "クロード"       # 名前（:claude）と表示名を分けたいとき

say "？？？", "ラー……テイラー……"
say :claude, "自動人形は家族だ。"
```

宣言しておくと `Novel/Validate Scenarios` の「未定義のキャラ id」警告も出なくなる。
逆に **宣言も登録もない名前は打ち間違いとして警告される**ので、宣言は忘れずに。

## say — セリフのもう 1 つの書き方

キャラ名で書くセリフは、実は `say` という命令の短縮形。どちらで書いても同じ。

```ruby
alice "こんにちは。"                # 短縮形
say "alice", "こんにちは。"          # 同じ意味
```

`say` の形だと、追加でできることが 2 つある。

```ruby
# 表示名を変える（as: と同じこと）
say "alice", "……。", display_as: "？？？"

# セリフと同時に立ち絵も切り替える（3 つ目に立ち絵の名前を書く）
say "alice", "え……！", "alice/surprised"
```

「驚いた瞬間に表情も変わる」ような演出は、この 3 つ目の書き方を使うと
立ち絵の切り替え（`portrait`、[4 章](./04-staging.md)）を別の行に書かずに済む。

## narration — 地の文

話者名なしで文章だけを表示する。

```ruby
narration "——彼女はこちらを見た。"
```

中身は **「話者を空欄にした `say`」**。だから `say` に文章だけを渡しても同じ地の文になる。

```ruby
say "——彼女はこちらを見た。"     # narration と同じ意味（話者を書かなければ地の文）
```

セリフも地の文も実体は同じ `say` で、話者がいるかいないかの違いだけ、と覚えておくとよい。

## 文中に変数の値を出す — テキスト変数 `%{}`

フラグや変数の値（[3 章](./03-branching.md)）を文章の中に出したいときは、
出したい位置に **`%{変数名}`** と書く。表示の瞬間の値に置き換わる。

```ruby
flag :gold, 500
narration "所持金は%{gold}Gだ"       # → 所持金は500Gだ
alice "見て、%{gold}Gも拾ったよ！"    # セリフでも選択肢でも使える
```

- 変数名は英数字とアンダースコアのみ（`%{gold}` / `%{route_a}`）
- 未定義の変数は `%{名前}` のまま表示される（書き間違いにすぐ気付ける）
- Ruby を知っている人へ: **`#{}` は使わないこと**。理由は [7 章](./07-pitfalls.md)

## 文章の途中で改行する

改行したい位置に `\n` と書く。セリフでも地の文でも使える。

```ruby
alice "考えても、\nわからなかった。"
```

表示はこうなる:

```
考えても、
わからなかった。
```

## 文中タグ — 文章の中に演出を埋め込む

セリフや地の文の中に `<…>` という形の **タグ** を埋め込むと、
表示の「間」や速さ、文字の見た目を細かく指定できる。

### 間・速さのタグ

| タグ | 効果 |
|---|---|
| `<w=秒数>` | その位置で指定した秒数だけ止まる（例: `<w=0.4>` で 0.4 秒） |
| `<p>` | その位置で止まり、プレイヤーのクリックを待つ |
| `<speed=2x>…</speed>` | 囲んだ部分の表示速度を変える（`2x` で 2 倍速、`0.5` で半分の速さ） |
| `<fast>` | それ以降を一気に表示する |

```ruby
alice "文字は<w=0.4>少しずつ<w=0.4>出るよ。"
alice "ここで一度止まる。<p>……続き。"
narration "<speed=0.5>ゆっくりと、</speed>時間が流れた。"
```

### 文字を動かすタグ

| タグ | 効果 |
|---|---|
| `<shake>…</shake>` | 囲んだ文字がガタガタ揺れる |
| `<wave>…</wave>` | 囲んだ文字が波打つ |

```ruby
alice "文字が<shake>ガタガタ</shake>する。"
```

> 文中の `<shake>` は **文字だけ** が揺れる。画面全体を揺らしたいときは
> `shake` 命令（[5 章](./05-audio-effects.md)）を使う。名前は同じだが別物。

### ふりがな

`<ruby=よみ>漢字</ruby>` の形で、漢字の上にふりがなを振れる。

```ruby
alice "<ruby=こと>異</ruby>の力が目覚めた。"
```

同じ語に毎回タグを書くのが大変な場合は、**ふりがな辞書** にまとめて登録しておける
（使えるかはプロジェクトの設定次第。置き場所の既定は `Resources/Novel/ruby.rb`）。

```ruby
ruby '異能', 'いのう'                    # 出てくるたびに毎回ふりがなを振る
ruby '主人公', 'しゅじんこう', :first     # 最初の 1 回だけ振る
```

「異能」と「異」を両方登録した場合は、長い方の「異能」が優先される。

### 文字の飾り（色・大きさなど）

色や大きさを変えるタグも使える。よく使うもの:

```ruby
alice "ここは <color=#8cf>novel-kit</color> の世界。"    # 色を変える
alice "<size=120%>大きな声</size>で言った。"             # 大きさを変える
alice "<b>太字</b>と<i>斜体</i>。"                       # 太字・斜体
```

これらは Unity のテキスト表示機能（TextMeshPro）のタグがそのまま通るもの。
他にどんなタグがあるかは[6 章の一覧](./06-reference.md)を参照。

### タグをそのまま文字として見せたいとき

- タグとして解釈されない `<` は普通の文字として表示される（`"3 < 5"` はそのまま書ける）。
- タグと解釈されてしまう書き方をそのまま画面に出したいときは `<noparse>…</noparse>` で囲む。

```ruby
narration "<noparse><shake> はタグです。</noparse>"    # 「<shake> はタグです。」と表示される
```

## バックログ（既読ログ）

表示したセリフは自動でバックログ（読み返し画面用の記録）に残る。ライター側の作業は不要。
