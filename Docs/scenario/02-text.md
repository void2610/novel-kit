# 2. セリフとテキスト表現

## キャラ宣言とセリフ

セリフを話すキャラは、シナリオ冒頭で `chara` を使って宣言する。
宣言したキャラは **id をそのまま命令として** 使える。

```ruby
chara :alice
chara :bob

alice "こんにちは。"
bob "やあ。"
```

- 話者の表示名（「アリス」など）や立ち絵は、ゲーム側のキャラカタログが id から解決する。
  カタログ未登録の id は id がそのまま表示されるので、使える id はプロジェクトの一覧を確認すること。
- `chara` を書き忘れて `alice "…"` と書くと **undefined method エラー** になる（実行時に検出）。

### 表示名の上書き（名前リビール）

正体を伏せたいときなどは `as:` でその行だけ表示名を上書きできる。

```ruby
alice "……誰かしら、あなた。", as: "？？？"
alice "私はアリスよ。"                       # 以降は通常の表示名
```

## say — セリフの基本形

キャラ名糖衣の実体は `say` 命令。直接書いてもよい。

```ruby
say "alice", "こんにちは。"                            # alice "こんにちは。" と同じ
say "alice", "……。", display_as: "？？？"              # 表示名上書き
say "alice", "え……！", "alice/surprised"               # 第 3 引数でこの行と同時に立ち絵を切り替え
say "地の文だけを書くとナレーションになる。"               # 引数 1 つ = 話者なし
```

第 3 引数の立ち絵キーを使うと、`portrait` を別行に書かずに
「セリフと同時に表情替え」ができる（表示名と立ち絵は独立に指定できる）。

## narration — 地の文

話者なしのテキスト。`say` の 1 引数形と同じ。

```ruby
narration "——彼女はこちらを見た。"
```

## インラインタグ（文中の演出）

本文中に `<...>` 形式のタグを埋め込むと、表示の間・速度・文字演出を制御できる。
記法は TMP（TextMeshPro）リッチテキストと同一系統。

### 進行制御タグ

| タグ | 効果 |
|---|---|
| `<w=N>` | その位置で N 秒待つ（例: `<w=0.4>`） |
| `<p>` | その位置でクリック待ち（送り入力があるまで停止） |
| `<speed=2x>…</speed>` | 囲んだ区間の表示速度を変える（`2x` で 2 倍速、`0.5` で半分） |
| `<fast>` | それ以降を即時表示 |

```ruby
alice "文字は<w=0.4>少しずつ<w=0.4>出るよ。"
alice "ここで一度止まる。<p>……続き。"
```

### 文字演出タグ

| タグ | 効果 |
|---|---|
| `<shake>…</shake>` | 囲んだ文字を揺らす |
| `<wave>…</wave>` | 囲んだ文字を波打たせる |

> 文中の `<shake>` は **文字** の演出。画面全体を揺らす `shake` 命令（[5 章](./05-audio-effects.md)）とは別物。

### ふりがな（ルビ）

```ruby
alice "<ruby=こと>異</ruby>の力が目覚めた。"
```

`<ruby=よみ>親文字</ruby>` で親文字の上によみを重ねて表示する。

頻出語に毎回タグを書くのが大変な場合は、**ルビ辞書**にまとめて登録できる
（配線されているかはプロジェクトによる）。既定の置き場所は `Resources/Novel/ruby.rb`:

```ruby
ruby '異能', 'いのう'            # 出てくるたびに毎回ルビを振る
ruby '主人公', 'しゅじんこう', :first   # 初出の 1 回だけ振る（:once でも同じ）
```

長い語が優先してマッチするので、「異能」と「異」を両方登録しても「異能」が先に効く。

### 文字装飾タグ（TMP スタイル）

`<color=#8cf>…</color>` `<size=120%>…</size>` `<b>…</b>` `<i>` `<u>` `<link>` など、
TMP のリッチテキストタグはそのまま使える。

```ruby
alice "ようこそ <color=#8cf>novel-kit</color> へ。"
```

### タグを文字として表示したいとき

- 対応外の `<` はそのまま文字として表示される（`"3 < 5"` は普通に書ける）。
- タグとして解釈されうる文字列をそのまま見せたい場合は `<noparse>…</noparse>` で囲む。

```ruby
narration "<noparse><shake> はタグです。</noparse>"
```

## バックログ（既読ログ）

表示したセリフは自動でバックログに積まれる（既定 200 行）。ライター側の操作は不要。
