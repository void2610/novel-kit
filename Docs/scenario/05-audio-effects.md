# 5. 音と演出効果

## bgm — BGM

```ruby
bgm "daily"      # BGM を再生（切り替え）
bgm ""           # 停止（引数省略でも同じ: bgm）
```

## se / se_loop — 効果音

```ruby
se "door_open"                 # 1 回再生
se_loop "knock", 0.5, 3        # 0.5 秒間隔で 3 回再生（間隔と回数は省略可。既定 0.5 秒 × 3 回）
```

使える音のキー一覧はゲーム側のカタログで決まる。

## wait — 待機

```ruby
wait 1.5         # 1.5 秒待ってから次の行へ
```

セリフ**文中**での待機は `<w=N>` タグの方が向いている（[2 章](./02-text.md)参照）。
`wait` は行と行の間、演出の「間」を作るのに使う。

## 世界エフェクト（画面・カメラへの効果）

画面全体やカメラに作用する演出。組込の糖衣は以下。

```ruby
shake 1.0          # 画面（カメラ）を揺らす。引数は強さ（省略時 1.0）
flash 0.2          # フラッシュ。引数は秒（省略時 0.2）
fade_out 1.0       # フェードアウト。引数は秒（省略時 1.0）
fade_in 1.0        # フェードイン。引数は秒（省略時 1.0）
blackout           # 即座に暗転（fade_out 0 相当）
```

```ruby
alice "後ろ……何かいる。"
shake 2.0
se "impact"
fade_out 1.5
narration "——意識が遠のいた。"
fade_in 1.0
```

### 知っておくべきこと

- 文中タグの `<shake>…</shake>`（文字が揺れる）とは別物。こちらは画面が揺れる。
- 世界エフェクトは **ゲーム側が実装を配線して初めて動く**。未配線なら何も起きない
  （開発中は Console に一度だけ警告が出る）。
- エフェクト完了を待ってから次の行へ進むか、待たずに進むかはゲーム側の実装次第。
  演出の「待ち」を確実に作りたい場合は `wait` を併用する。
- プロジェクト固有のエフェクトが追加されている場合は、汎用形で呼べる:

```ruby
world_effect :zoom, 1.5, 0.8     # エフェクト名と数値引数（内容はプロジェクト定義）
```

## プロジェクト独自の命令

組込命令のほかに、ゲーム固有の命令（ミニゲーム起動・実績解除など）が
追加されていることがある。その場合は次のどちらかの形で呼ぶ。

```ruby
screen_shake 2.0                  # 糖衣（関数）が用意されている場合
cmd :screen_shake, power: 2.0     # 汎用形（cmd 命令名, 引数名: 値, ...）
```

何が追加されているかはプロジェクトのドキュメント・エンジニアに確認すること。
