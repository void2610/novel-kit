# 5. 音と演出効果

## bgm — BGM を流す・止める

```ruby
bgm "daily"      # BGM「daily」を流す（別の曲が流れていれば切り替え）
bgm ""           # 止める（名前を空にする。bgm とだけ書いても同じ）
```

## se / se_loop — 効果音

```ruby
se "door_open"                 # 1 回鳴らす
se_loop "knock", 0.5, 3        # 0.5 秒おきに 3 回鳴らす（ノックなど）
se_loop "knock"                # 秒数と回数を省くと 0.5 秒おきに 3 回
```

使える音の名前はゲーム側の設定で決まる。一覧は Unity のメニュー
**Novel > Project Reference** で確認できる。

## wait — 間を取る

指定した秒数だけ止まってから次の行へ進む。

```ruby
narration "扉の向こうで、物音がした。"
wait 1.5
narration "……気のせいだろうか。"
```

セリフの **文中** で間を取りたいときは `<w=秒数>` タグの方が向いている（[2 章](./02-text.md)参照）。
`wait` は行と行のあいだ、演出と演出のあいだの「間」に使う。

## 画面全体への効果（揺れ・フラッシュ・フェード）

画面全体やカメラに働く演出。カッコ内の数字は省略でき、省略時は（ ）内の値になる。

```ruby
shake 2.0          # 画面を揺らす。数字は強さ（省略時 1.0）
flash              # 画面を一瞬光らせる。数字は秒数（省略時 0.2）
fade_out 1.5       # だんだん暗くする。数字は秒数（省略時 1.0）
fade_in            # だんだん明るくする。数字は秒数（省略時 1.0）
blackout           # 一瞬で真っ暗にする
```

組み合わせの例:

```ruby
alice "後ろ……何かいる。"
shake 2.0
se "impact"
fade_out 1.5
narration "——意識が遠のいた。"
fade_in 1.0
```

### 知っておくべきこと

- 文中タグの `<shake>…</shake>` は **文字** が揺れる。こちらの `shake` は **画面** が揺れる。別物。
- これらの効果は **ゲーム側に対応する仕組みが組み込まれて初めて動く**。
  組み込まれていない場合は何も起こらない（開発中は Console に一度だけ警告が出る）。
- 効果の終わりを待ってから次の行に進むかどうかは、ゲーム側の作りによる。
  「フェードが終わってから次のセリフ」を確実にしたいときは `wait` を添えておくと安全。

## cinematic — 用意された演出を名前で呼ぶ

ゲーム側で作り込まれた演出（回想の質感、ビネット、モノクロ化など）を名前で呼ぶ。
`shake` などと違い、演出の中身はゲーム側のアセットで決まっていて、シナリオからは名前だけ指定する。

```ruby
cinematic :flashback        # 演出「flashback」を始める
alice "あの日のことは、今でも……。"
cinematic_stop :flashback   # 演出「flashback」を終える（元に戻す）
```

- 使える演出の名前は **Novel > Project Reference** の「演出」タブで確認できる。
  `cinematic_stop` が使えるのは一覧に「_exit あり」と出ている演出だけ。一回で終わる演出には要らない。
- 終わりを待つかどうかは演出ごとの作り次第。
- 存在しない名前を書くと何も起きないが、開発中は Console に警告が出る。

## プロジェクト独自の命令

ここまでの標準の命令のほかに、そのゲーム専用の命令（ミニゲームを始める、実績を解除する等）が
追加されていることがある。追加のされ方によって、書き方は 2 通りある。

```ruby
screen_shake 2.0                  # 専用の命令として用意されている場合（普通の命令と同じ書き方）
cmd :screen_shake, power: 2.0     # 用意されていない場合の直接指定（項目名: 値 の形で内容を渡す）
```

なにが追加されているか、どちらの書き方を使うかは、プロジェクトの資料・エンジニアに確認すること。
