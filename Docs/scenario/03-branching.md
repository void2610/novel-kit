# 3. 選択肢・フラグ・分岐

この章だけは少し「プログラムらしい」書き方が出てくる。
とはいえ使うのは **選択肢を出す・結果を覚える・結果で分ける** の 3 つだけ。順に見ていく。

## choose — 選択肢を出す

`choose` は選択肢を画面に表示し、プレイヤーがどれを選んだかを **番号** で教えてくれる。
番号は **0 から数える**（1 つ目 = 0、2 つ目 = 1、3 つ目 = 2 …）ことに注意。

```ruby
n = choose(["はい", "いいえ"])
```

`n = ` の部分は「選ばれた番号に **n という名前を付けて覚えておく**」という意味
（名前は `n` でなくてもよい）。覚えた番号は、次の「分岐」で使う。

## if — 結果によってセリフを分ける

「もし〜なら」は `if` で書く。**`if` で始めたら、最後に必ず `end` で閉じる**。

```ruby
n = choose(["はい", "いいえ", "考えさせて"])
if n == 0                       # もし n が 0（= 1 つ目「はい」）なら
  alice "うれしい！"
elsif n == 1                    # そうではなくて、n が 1（= 2 つ目「いいえ」）なら
  alice "そっか……。"
else                            # 上のどれでもなければ
  alice "ゆっくり考えて。"
end                             # 分岐ここまで
```

- `==` は「等しいかどうか」を調べる書き方（`=` を 2 つ重ねる）。
- 途中の `elsif`（〜なら）や `else`（どれでもなければ）は、不要なら書かなくてよい。
- 分岐の中の行は、読みやすさのため字下げ（スペース 2 つ）するのが慣例。

## flag / val — フラグ: 結果をずっと覚えておく

`n` のような名前は **その場かぎりの覚え書き** で、長くは残らない（詳細は後述）。
シーンや章をまたいで残したい情報は **フラグ** に記録する。

フラグは「名前の付いた箱」で、**中に入れられるのは整数（0, 1, 2, …）だけ**。
セーブデータに保存されるので、ロード後も周回後も残る。

```ruby
flag :met_alice          # 箱「met_alice」に 1 を入れる（=「済んだ」印を立てる）
flag :score, 5           # 箱「score」に 5 を入れる
flag :met_alice, 0       # 0 を入れ直す（= 印を消す）

val(:score)              # 箱「score」の中身を読む。一度も入れていない箱は 0
flag?(:met_alice)        # 印が立っているか（中身が 0 以外か）を調べる
```

使いどころの典型:

```ruby
if flag?(:met_alice)
  alice "また会ったね。"
else
  alice "はじめまして。"
  flag :met_alice        # 「会った」印を立てておく → 次からは上のセリフになる
end
```

計算して入れ直すこともできる:

```ruby
flag :score, val(:score) + 10     # 今の score に 10 足す
```

## 選択の結果をセーブに残す — key: 付き choose

選択肢の結果を後々まで使いたいときは、`choose` に `key: :名前` を書き添える。
選んだ番号が **その名前のフラグに自動で記録され**、別のシナリオからも読める。

```ruby
choose(["真実を話す", "黙っている"], key: :ask_truth)

# --- 別のシナリオ（後日談など）でも読める ---
if val(:ask_truth) == 0
  alice "あのとき話してくれて、ありがとう。"
end
```

使い分けの目安:

- **その場の分岐にしか使わない選択** → `n = choose([...])` でよい
- **後のシーン・別のシナリオ・周回で参照する選択** → 必ず `key:` を付ける

フラグの名前はプロジェクト内で共通なので、重複しない名前を付けること。
また、`__`（アンダースコア 2 つ）で始まる名前はシステム用なので使わない。

## case — 3 つ以上に分けるとき

分け先が多いときは `case` を使うと読みやすい。

```ruby
case val(:route)
when 0 then alice "共通ルートだね。"
when 1 then alice "私のルートへようこそ。"
else        alice "……どこかで会った？"
end
```

1 行だけの条件なら、後ろに付ける書き方もある:

```ruby
alice "その傷、どうしたの？" if flag?(:injured)      # injured の印が立っているときだけ言う
```

## エンディング分岐はどうやるの？ — ゲーム側との分担

シナリオファイルには「終わり方」は 1 種類しかない（最後の行まで進んだら終わり）。
ルート分岐やエンディングの出し分けは、**シナリオがフラグを残し、
ゲーム側がフラグを見て次に再生するシナリオを決める** という分担で実現する。
「どの名前のフラグにどの値を入れるか」はエンジニアと取り決めておくこと。

## 注意: `n = …` の覚え書きは長持ちしない

`n = choose(...)` の `n` のようなその場の覚え書きは、**選択肢の直後の分岐で使う分には
問題ない** が、間にセリフや演出をたくさん挟んでから使うと消えていることがある
（仕組み上の制約。詳細は [7 章](./07-pitfalls.md)）。

```ruby
# ◯ 安全: 直後に使う
n = choose(["A", "B"])
if n == 0
  ...
end

# ✕ 危険: 間にいろいろ挟んでから使う
n = choose(["A", "B"])
alice "……そう。"
narration "しばらくして。"
if n == 0          # ここで n が消えていることがある
  ...
end

# ◯ 安全: 後で使うなら key: 付きで記録しておく
choose(["A", "B"], key: :picked)
alice "……そう。"
narration "しばらくして。"
if val(:picked) == 0
  ...
end
```

**原則: 後で使う結果は、必ず `flag` か `key:` 付き `choose` で残す。**
