# 3. 選択肢・フラグ・分岐

## choose — 選択肢

選択肢を表示し、プレイヤーが選んだ番号（**0 始まり**）を返す。

```ruby
n = choose(["はい", "いいえ", "考えさせて"])
if n == 0
  alice "うれしい！"
elsif n == 1
  alice "そっか……。"
else
  alice "ゆっくり考えて。"
end
```

### 結果をセーブに残したいとき — key:

`key:` を付けると、選んだ番号がその名前のフラグとして **セーブに残り**、
別のシナリオからも読める。

```ruby
choose(["真実を話す", "黙っている"], key: :ask_truth)

# --- 別シナリオ（後日談など）でも読める ---
if val(:ask_truth) == 0
  alice "あのとき話してくれて、ありがとう。"
end
```

- `key:` **なし** → その場で使う一時的な選択。セーブには残らない。
- `key:` **あり** → 安定した名前で記録され、セーブ対象になる。周回や章跨ぎで参照する選択には必ず付ける。

キー名は他のフラグと同じ空間を共有するので、プロジェクト内で重複しない名前を付けること
（`__`（アンダースコア 2 つ）始まりの名前は内部予約なので使わない）。

## flag / val / flag? — フラグと変数

フラグ・変数は「名前 → 整数」の 1 つの表で管理される。**値は整数のみ**
（文字列や小数は入れられない）。セーブ対象。

```ruby
flag :answered              # 値を省略すると 1（= フラグを立てる）
flag :score, 5              # 数値を入れる
flag :answered, 0           # 0 に戻す（= フラグを下ろす）

val(:score)                 # 読み出し。未設定の名前は 0
flag?(:answered)            # 真偽判定。0 以外なら真
```

```ruby
if flag?(:met_alice)
  alice "また会ったね。"
else
  alice "はじめまして。"
  flag :met_alice
end

narration "現在のスコア: #{val(:score)} 点。"
```

計算して入れ直すこともできる:

```ruby
flag :score, val(:score) + 10
```

## 分岐の書き方いろいろ

Ruby の制御構文がそのまま使える。よく使うのは以下。

```ruby
# 条件付き 1 行（後置 if / unless）
alice "その傷、どうしたの？" if flag?(:injured)
alice "元気そうだね。" unless flag?(:injured)

# 多分岐（case）
case val(:route)
when 0 then alice "共通ルートだね。"
when 1 then alice "私のルートへようこそ。"
else        alice "……どこかで会った？"
end
```

## ゲーム側との分担

シナリオの終わり方は 1 通り（最後まで実行されたら終了）で、
「どの選択肢を選んだか」「好感度がいくつか」は全部フラグに残す。
**次にどのシナリオを再生するかを決めるのはゲーム側** で、ゲームはフラグを読んで判断する。
エンディング分岐などは「どのフラグをどの値にするか」をエンジニアと取り決めておくこと。

## 注意: 選択結果はすぐ使うか、フラグに残す

`n = choose(...)` の結果 `n` のような一時変数は、その直後の分岐で使う分には問題ないが、
**間に多数の演出やクリック待ちを挟んで後から使うのは避ける**（mruby の内部制約により
一時変数が消える場合がある。詳細は [7 章](./07-pitfalls.md)）。
時間や場面を跨いで参照する結果は `key:` 付き `choose` か `flag` で残すのが確実。

```ruby
# ◯ 安全: 直後に判定
n = choose(["A", "B"])
if n == 0
  ...
end

# ◯ 安全: 後で使うならフラグに
choose(["A", "B"], key: :first_choice)
# …長い演出…
if val(:first_choice) == 0
  ...
end
```
