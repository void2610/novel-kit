# シナリオライターズガイド — novel-kit

novel-kit でシナリオ（`.rb` ファイル）を書く人のためのドキュメント。
プログラミングの知識がなくても、ここに書いてある範囲でシナリオを完成させられることを目標にしている。

> ⚠️ **API は流動的です。** 本ライブラリは実装初期段階で、命令名・記法は予告なく変わります。
> 変更があった場合は本ガイドも合わせて更新されます。

## 対象読者

- セリフ・地の文・演出指定を書くシナリオライター
- ライターの書いたシナリオをレビュー・組み込みするエンジニア

エンジニア向けのセットアップ・配線手順は [Getting Started](../getting-started.md) を参照。
独自コマンドの追加方法（C# 側）もそちらに記載している。

## 構成

順番に読めば一本のシナリオを書けるようになる構成。リファレンスだけ引きたい場合は 6 章へ。

| [1. シナリオファイルの基本](./01-basics.md) | ファイルの置き場所・書き方のルール・動作確認の方法 |
| [2. セリフとテキスト表現](./02-text.md) | セリフ・地の文・表示名・文中タグ（間・速度・文字揺れ・ふりがな） |
| [3. 選択肢・フラグ・分岐](./03-branching.md) | 選択肢の出し方、フラグの読み書き、条件分岐、セーブに残る/残らないの区別 |
| [4. 画面演出（立ち絵・背景）](./04-staging.md) | 場面（stage）と立ち絵、背景・一枚絵・補足画像、メッセージウィンドウ制御 |

## 最小サンプル

```ruby
chara :alice                       # 登場キャラを宣言（以降 alice "…" で話せる）

bg "room"                          # 背景
bgm "daily"                        # BGM
stage :single, [:alice]            # 場面: 1 人レイアウトにアリスを配置
portrait :alice, "smile"           # 立ち絵

alice "やあ、ようこそ。"
narration "——彼女はこちらを見た。"

n = choose(["はい", "いいえ"])       # 選択肢（0 始まりの番号が返る）
if n == 0
  alice "うれしい！"
else
  alice "そっか……。"
end
```

このサンプルの完全版はリポジトリの `Assets/Novel/Samples~/Basic/Resources/Scenarios/sample.rb` にある。
