# シナリオライターズガイド — novel-kit

novel-kit でシナリオ（`.rb` ファイル）を書く人のためのドキュメント。
**プログラミングの知識は前提にしません。** ここに書いてある範囲で
シナリオを完成させられることを目標にしている。

> ⚠️ **書き方は変わることがあります。** 本ライブラリは開発初期段階のため、
> 記法は予告なく変わります。変更があった場合は本ガイドも合わせて更新されます。

## 対象読者

- セリフ・地の文・演出指定を書くシナリオライター
- ライターの書いたシナリオをレビュー・組み込みするエンジニア

エンジニア向けのセットアップ・組み込み手順は [Getting Started](../getting-started.md) を参照。

## まず見てみる — 最小サンプル

シナリオは、下のような「台本」をテキストファイルに書いていくもの。
`#` から後ろはメモ書き（実行されない）なので、注釈として読んでほしい。

```ruby
chara :alice                  # 「alice」というキャラが登場します、という宣言

bg "room"                     # 背景を「room」に切り替え
bgm "daily"                   # BGM「daily」を流す
portrait :alice, "smile"      # alice の立ち絵「smile」を表示

alice "やあ、ようこそ。"        # alice のセリフ
narration "——彼女はこちらを見た。"   # 地の文（ナレーション）

n = choose(["はい", "いいえ"])  # 選択肢を表示。選んだ結果を n という名前で覚える
if n == 0                     # 1 つ目（はい）を選んでいたら…
  alice "うれしい！"
else                          # そうでなければ…
  alice "そっか……。"
end                           # 分岐ここまで
```

このサンプルの完全版はリポジトリの `Assets/Novel/Samples~/Basic/Resources/Scenarios/sample.rb` にある。
